# مسابقات والیبال گلبهار

سامانه مدیریت و نمایش زنده نتایج مسابقات والیبال.

## نحوه اجرا

فایل `index.html` کامل و مستقل است. کافی است آن را روی هر هاستی قرار دهید.

### ساختار (نسخه چندفایلی هم موجود است)

```
├── index.html      # نسخه کامل تک‌فایلی (پیشنهادی برای هاست)
├── css/styles.css
├── js/app.js
├── vercel.json
└── README.md
```

## استقرار روی هاست

### هاست معمولی (cPanel)
فقط `index.html` را در `public_html` آپلود کنید.

### Vercel
1. این ریپو را در [vercel.com](https://vercel.com) ایمپورت کنید
2. Deploy

### Netlify
فایل یا پوشه را Drag & Drop کنید.
