## آدرس‌ها

| صفحه | مسیر |
|------|------|
| سایت عمومی | `/` یا `index.html` |
| پنل مدیریت | `/admin.html` |

رمز ادمین: `golbahar1403`

## ذخیره برای همه گوشی‌ها

1. وارد `admin.html` شوید
2. از منو **ذخیره ابری** را باز کنید
3. روی **فعال‌سازی ذخیره ابری** بزنید
4. شناسه (Bin ID) را کپی کنید
5. اگر روی گوشی/لپ‌تاپ دیگری ادمین می‌شوید، همان شناسه را وارد کنید

بعد از فعال‌سازی، نتایج برای همه بازدیدکننده‌ها یکسان می‌شود (هر ۱۵ ثانیه همگام می‌شود).

## نصب روی موبایل (PWA)

- اندروید/کروم: منو → Add to Home Screen / نصب برنامه
- آیفون: Share → Add to Home Screen
