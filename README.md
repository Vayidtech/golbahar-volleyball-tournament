# مسابقات والیبال گلبهار

سامانه مدیریت و نمایش زنده نتایج مسابقات والیبال گلبهار.

## ساختار پروژه

```
golbahar-volleyball-tournament/
├── index.html
├── css/styles.css
├── js/app.js
├── vercel.json
└── README.md
```

سایت کاملاً استاتیک است. داده‌ها در localStorage مرورگر ذخیره می‌شوند.

## رمز ادمین

```
golbahar1403
```

## استقرار

### Vercel
Import این ریپو در vercel.com یا:
```bash
npx vercel
```

### هاست معمولی
محتویات را در public_html آپلود کنید.

### Netlify
پوشه را drag & drop کنید.
