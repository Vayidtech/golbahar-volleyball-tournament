# مسابقات والیبال گلبهار - اپلیکیشن مدیریت تورنمنت

یک وب‌اپ ساده برای مدیریت مسابقات والیبال با مرحله گروهی و حذفی.

## ویژگی‌ها

### برای ادمین (رمز ثابت: `golbahar1404`)
- تنظیم تعداد تیم‌ها و تعداد در هر گروه
- وارد کردن نام تیم‌ها
- آپلود لوگو برای هر تیم
- قرعه‌کشی تصادفی گروه‌ها + ساخت خودکار بازی‌های گروهی (round-robin)
- جابجایی دستی محدود
- ثبت نتایج (ست‌ها: ۲-۰ یا ۲-۱)
- امتیازدهی: ۲-۰ → ۳ امتیاز | ۲-۱ → ۲ برای برنده + ۱ برای بازنده
- رتبه‌بندی با تفاضل ست در صورت تساوی امتیاز
- محاسبه ۱۲ تیم صعودکننده (۲ تا از هر گروه + بهترین تیم‌های دوم)
- دور ۱۲ تیمی → ۶ برنده + ۲ بهترین بازنده (بر اساس ست) → ۸ تیم
- یک‌چهارم، نیمه‌نهایی، رده‌بندی و فینال
- برنامه‌ریزی روز و ساعت هر بازی
- پشتیبان‌گیری و بازیابی با فایل JSON

### برای کاربران عادی
- مشاهده جداول گروه‌ها با امتیاز و ست
- دیدن نتایج و برنامه بازی‌ها
- تیم‌های صعودکننده

## نحوه استفاده محلی

فقط فایل `index.html` را در مرورگر باز کنید.

یا با یک سرور ساده:

```bash
npx serve .
```

## دیپلوی روی Vercel

1. یک ریپو در GitHub بسازید و این فایل‌ها را push کنید.
2. در [vercel.com](https://vercel.com) پروژه جدید بسازید و ریپو را انتخاب کنید.
3. Framework Preset: Other
4. Build Command: خالی بگذارید
5. Output Directory: `.`
6. Deploy

لینک عمومی برای همه و `/admin-login` برای ادمین.

## نکات مهم

- داده‌ها در **localStorage** مرورگر ذخیره می‌شوند.
- برای اشتراک بین چند دستگاه/کاربر: از تب «پشتیبان‌گیری» فایل JSON را دانلود کنید و در دستگاه دیگر بارگذاری کنید.
- برای استفاده واقعی چندکاربره و همزمان، پیشنهاد می‌شود Firebase Firestore اضافه شود (کد آماده اتصال است، فقط config را بگذارید).
- رمز ادمین را در خط مربوط به `ADMIN_PASSWORD` در فایل HTML تغییر دهید.

## ساختار تورنمنت پیش‌فرض (۲۰ تیم)

- ۵ گروه ۴ تیمی
- از هر گروه ۲ تیم + ۲ بهترین تیم دوم → ۱۲ تیم
- دور ۱۲ تیمی → ۶ برنده + ۲ بهترین بازنده → ۸ تیم
- یک‌چهارم → نیمه‌نهایی → فینال + رده‌بندی
